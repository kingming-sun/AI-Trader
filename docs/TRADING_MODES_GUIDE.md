# 交易模式说明文档

## 📋 概述

AI-Trader 平台支持三种交易模式，每种模式适用于不同的场景和需求。本文档详细说明三种模式的区别、配置和使用方法。

---

## 🎯 三种模式对比

| 特性 | 回测 (Backtest) | 模拟盘 (Simulate) | 实盘 (Real) |
|------|----------------|------------------|------------|
| **数据来源** | 历史价格数据 (`merged.jsonl`) | Moomoo 实时市场数据 | Moomoo 实时市场数据 |
| **交易执行** | 模拟交易（无真实下单） | 模拟交易（无真实资金） | 真实交易（真实资金） |
| **资金风险** | 无风险 | 无风险 | **有风险** |
| **日期范围** | 需要设置历史日期范围 | **从当前时间开始** | **从当前时间开始** |
| **运行方式** | 一次性运行，处理完所有日期后结束 | 持续运行，直到手动停止 | 持续运行，直到手动停止 |
| **主要用途** | 策略验证和优化 | 真实市场环境测试 | 真实交易执行 |
| **配置要求** | 需要设置日期范围 | 无需设置日期范围 | 无需设置日期范围 + 风险确认 |

---

## 📊 详细说明

### 1. 回测模式 (Backtest)

#### 核心特点
- **使用历史数据**：从本地 `merged.jsonl` 文件读取历史价格数据
- **设置日期范围**：必须指定开始日期和结束日期
- **一次性运行**：处理完指定日期范围内的所有交易日后自动结束
- **无资金风险**：完全模拟，不涉及真实资金

#### 使用场景
- ✅ 验证策略在历史数据上的表现
- ✅ 优化策略参数
- ✅ 测试不同的交易逻辑
- ✅ 分析策略在不同市场环境下的表现

#### 配置要求
```json
{
  "date_range": {
    "init_date": "2025-10-20",  // 必填：开始日期
    "end_date": "2025-10-27"    // 必填：结束日期
  },
  "agent_config": {
    "max_steps": 30,
    "initial_cash": 10000
  }
}
```

#### 运行流程
1. 用户设置日期范围（例如：2025-10-20 到 2025-10-27）
2. 点击"开始回测"
3. 系统按顺序处理日期范围内的每个交易日
4. 处理完所有日期后自动结束
5. 生成结果文件（`asset_evolution.json`, `portfolio.json`, `trades.json`）

---

### 2. 模拟盘模式 (Simulate)

#### 核心特点
- **使用实时数据**：从 Moomoo API 获取实时市场数据
- **从当前时间开始**：启动后立即开始交易，使用当前市场数据
- **持续运行**：不会自动结束，需要手动停止
- **模拟交易**：使用 Moomoo 模拟账户，无真实资金
- **无需设置日期范围**：日期由系统自动设置为当前日期

#### 使用场景
- ✅ 在真实市场环境下测试策略
- ✅ 验证策略在实时数据上的表现
- ✅ 测试 Moomoo API 集成
- ✅ 在无风险环境下观察策略行为

#### 配置要求
```json
{
  "date_range": {
    "init_date": "2025-11-06",  // 自动设置为当前日期
    "end_date": "2025-11-06"    // 自动设置为当前日期
  },
  "agent_config": {
    "max_steps": 30,
    "initial_cash": 10000
  },
  "moomoo_env": "SIMULATE"  // 使用模拟环境
}
```

#### 运行流程
1. 用户点击"开始模拟盘"
2. 系统自动设置日期为当前日期
3. 连接到 Moomoo 模拟账户
4. **从当前时间开始持续交易**
5. 每个交易日处理当天的交易决策
6. 需要手动点击"停止运行"才会结束

#### 重要说明
- ⚠️ **不需要设置日期范围**：系统自动使用当前日期
- ⚠️ **持续运行**：不会自动结束，需要手动停止
- ⚠️ **实时数据**：依赖 Moomoo API，需要网络连接

---

### 3. 实盘模式 (Real)

#### 核心特点
- **使用实时数据**：从 Moomoo API 获取实时市场数据
- **从当前时间开始**：启动后立即开始交易，使用当前市场数据
- **持续运行**：不会自动结束，需要手动停止
- **真实交易**：使用真实资金执行交易
- **无需设置日期范围**：日期由系统自动设置为当前日期
- **风险控制**：自动应用风险控制参数

#### 使用场景
- ⚠️ **真实交易执行**：使用真实资金进行交易
- ⚠️ **生产环境**：策略已经通过回测和模拟盘验证

#### 配置要求
```json
{
  "date_range": {
    "init_date": "2025-11-06",  // 自动设置为当前日期
    "end_date": null             // 持续运行，无结束日期
  },
  "agent_config": {
    "max_steps": 30,
    "initial_cash": 10000
  },
  "moomoo_env": "REAL",  // 使用实盘环境
  "risk_control": {
    "max_daily_loss": 0.05,
    "max_position_size": 0.2,
    "stop_loss": 0.1
  }
}
```

#### 运行流程
1. 用户点击"开始实盘"（需要二次确认）
2. 系统自动设置日期为当前日期
3. 连接到 Moomoo 实盘账户
4. **从当前时间开始持续交易**
5. 每个交易日处理当天的交易决策
6. 应用风险控制参数
7. 需要手动点击"停止运行"才会结束

#### 重要说明
- ⚠️ **真实资金风险**：会使用真实资金进行交易
- ⚠️ **不需要设置日期范围**：系统自动使用当前日期
- ⚠️ **持续运行**：不会自动结束，需要手动停止
- ⚠️ **风险控制**：务必配置并启用风险控制参数
- ⚠️ **建议流程**：先回测 → 再模拟盘 → 最后实盘

## 🔄 推荐使用流程

### 策略开发流程
```
1. 回测模式
   ↓
   验证策略在历史数据上的表现
   ↓
2. 模拟盘模式
   ↓
   验证策略在实时市场环境下的表现
   ↓
3. 实盘模式
   ↓
   使用真实资金执行交易
```

### 每个阶段的检查点

#### 回测阶段
- ✅ 策略在历史数据上表现良好
- ✅ 收益率、最大回撤等指标符合预期
- ✅ AI 决策逻辑合理（查看日志）

#### 模拟盘阶段
- ✅ 策略在实时市场环境下正常工作
- ✅ Moomoo API 集成正常
- ✅ 风险控制参数有效
- ✅ 运行稳定（无异常中断）

#### 实盘阶段
- ✅ 已充分测试（回测 + 模拟盘）
- ✅ 风险控制参数已配置
- ✅ 已准备好承担交易风险
- ✅ 监控机制已建立

## ❓ 常见问题

### Q1: 为什么模拟盘和实盘不需要设置日期范围？
**A**: 模拟盘和实盘使用实时市场数据，从启动时开始交易。系统会自动将日期设置为当前日期，并持续运行直到手动停止。

### Q2: 回测可以设置未来的日期吗？
**A**: 不建议。回测使用历史数据，如果设置未来日期，系统可能无法获取数据或使用错误的日期。

### Q3: 模拟盘和实盘运行多久？
**A**: 持续运行，直到手动点击"停止运行"按钮。系统会每天处理当天的交易，不会自动结束。

### Q4: 如何停止模拟盘或实盘？
**A**: 在资产演变页面，点击"停止运行"按钮。系统会安全地停止当前交易并保存数据。

### Q5: 模拟盘和实盘的区别是什么？
**A**: 
- **模拟盘**：使用模拟账户，无真实资金，用于测试
- **实盘**：使用真实账户，真实资金，用于实际交易
