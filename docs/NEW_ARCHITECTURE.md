## 🎯 概述

本文档描述 AI-Trader 平台的前端界面新架构。新架构采用清晰的功能分区和模块化设计，提供更直观的用户体验，使用户能够高效地管理交易策略、监控平台服务并分析交易表现。

### 设计原则

- **清晰导航**：功能入口明确，层级结构简单
- **模块化设计**：每个功能模块独立，便于维护和扩展
- **数据可视化**：直观展示策略表现和平台状态
- **模式区分**：明确区分回测、模拟盘、实盘三种运行模式

## 📊 策略管理界面

### 功能概述

策略管理界面是策略的列表视图，提供策略的创建、查看和管理功能。

### 界面布局

```
┌─────────────────────────────────────────────────┐
│  策略管理                           [+ 创建新策略] │
├─────────────────────────────────────────────────┤
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │ 策略名称: 保守型策略                      │   │
│  │ 描述: 低风险、稳定收益的策略               │   │
│  │ 状态: 运行中 | 最后更新: 2025-11-04      │   │
│  │ [查看详情] [运行回测] [运行模拟] [运行实盘]│   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │ 策略名称: 激进型策略                      │   │
│  │ 描述: 高风险、高收益的策略                 │   │
│  │ 状态: 设计中 | 最后更新: 2025-11-03      │   │
│  │ [查看详情] [编辑] [删除]                  │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 功能模块

#### 1. 策略列表展示

- **显示内容**：
  - 策略名称
  - 策略描述
  - 当前状态（设计中/回测中/模拟盘中/实盘中/已归档）
  - 最后更新时间
  - 快速操作按钮

- **列表功能**：
  - 搜索：按策略名称搜索
  - 筛选：按状态筛选（设计中/运行中/已归档）
  - 排序：按创建时间、更新时间、状态排序
  - 分页：支持大量策略的分页显示

#### 2. 创建新策略

- **入口**：页面右上角 "+ 创建新策略" 按钮
- **创建流程**：
  1. 输入策略名称和描述
  2. 选择基础 Prompt 模板（可选）
  3. 配置初始参数（初始资金等，注意：日期范围仅在回测配置中设置）
  4. 确认创建

- **创建后**：
  - 自动跳转到策略详情页面的"配置管理"模块
  - 可以继续完善配置

#### 3. 删除策略

- **入口**：策略卡片上的"删除"按钮
- **删除流程**：
  1. 点击"删除"按钮
  2. 弹出确认对话框（显示策略名称和警告信息）
  3. 确认删除后，删除策略配置和数据文件
  4. 更新策略列表

- **注意事项**：
  - ⚠️ 删除操作不可恢复，会删除策略的所有配置和数据
  - ⚠️ 如果策略正在运行，需要先停止运行才能删除
  - 删除前会显示策略的基本信息（创建时间、运行状态等）

### 策略卡片操作

每个策略卡片提供以下操作：

- **查看详情**：进入策略详情界面
- **运行回测**：快速启动回测（使用默认配置）
- **运行模拟**：快速启动模拟盘（使用默认配置）
- **运行实盘**：启动实盘交易（需要确认）
- **编辑**：编辑策略基本信息
- **删除**：删除策略（需要确认，⚠️ 不可恢复）

#### 删除策略功能详解

- **删除按钮位置**：策略卡片右下角，使用红色样式
- **删除确认**：
  - 显示策略名称和创建时间
  - 警告：此操作将删除策略的所有配置和数据，且不可恢复
  - 如果策略正在运行，提示先停止运行
- **删除范围**：
  - 策略配置文件（`configs/strategies/{id}/`）
  - 策略运行数据（`data/strategies/{id}/`）
  - 策略的所有模式数据（回测、模拟、实盘）

### 模块一：配置管理

#### 功能概述

配置管理模块允许用户查看和修改策略的各项配置参数。

#### 界面内容

```
配置管理
├─ Prompt 管理
│  ├─ 基础 Prompt（所有模式共用）
│  ├─ 回测 Prompt（可选，覆盖基础 Prompt）
│  ├─ 模拟盘 Prompt（可选，覆盖基础 Prompt）
│  └─ 实盘 Prompt（可选，覆盖基础 Prompt）
│
├─ Agent 配置参数（所有模式共用）
│  ├─ max_steps: 最大推理步数
│  ├─ max_retries: 最大重试次数
│  ├─ base_delay: 基础延迟时间
│  └─ initial_cash: 初始资金
│
├─ 模型配置（所有模式共用）
│  ├─ 选择使用的 AI 模型
│  ├─ 模型 API 配置
│  └─ 模型启用状态
│
└─ 模式特定配置
   ├─ 回测配置
   │  ├─ 交易日期范围（仅回测使用）
   │  │  ├─ 开始日期
   │  │  └─ 结束日期
   │  └─ 历史数据设置
   │
   ├─ 模拟盘配置
   │  ├─ Moomoo 模拟账户设置
   │  └─ 自动启动设置（是否在启动时自动开始交易）
   │
   └─ 实盘配置
      ├─ Moomoo 实盘账户设置
      ├─ 风险控制参数
      │  ├─ max_daily_loss: 最大单日亏损
      │  ├─ max_position_size: 单只股票最大仓位
      │  └─ stop_loss: 止损比例
      └─ 自动启动设置（是否在启动时自动开始交易）
```

#### 操作功能

- **加载配置**：从文件加载当前配置（按当前选择的模式）
- **保存配置**：保存修改后的配置（保存到对应模式的配置）
- **重置**：恢复默认配置
- **验证**：检查配置的有效性
- **重启服务**：修改配置后，需要重启服务才能生效（显示重启按钮）

#### 配置管理模式

配置管理界面顶部显示模式选择器，允许用户分别为不同模式配置：

1. **基础配置**（所有模式共用）
   - Agent 参数
   - 模型配置
   - 基础 Prompt

2. **回测配置**（仅回测模式）
   - 交易日期范围（必填）
   - 历史数据设置

3. **模拟盘配置**（仅模拟盘模式）
   - Moomoo 模拟账户设置
   - 自动启动设置

4. **实盘配置**（仅实盘模式）
   - Moomoo 实盘账户设置
   - 风险控制参数
   - 自动启动设置

#### 配置保存和生效

- **保存配置**：点击"保存配置"按钮后
  - 配置保存到对应模式的文件
  - 显示"配置已保存，需要重启服务才能生效"提示
  - 显示"重启服务"按钮

- **重启服务**：
  - 点击"重启服务"按钮
  - 确认对话框：重启将停止当前运行的任务
  - 重启后，新配置生效
  - 如果策略正在运行，会先停止再重启

- **配置生效时机**：
  - 修改配置后需要重启服务才能生效
  - 正在运行的策略不会自动应用新配置
  - 新启动的策略会使用最新配置

### 模块二：资产演变

#### 功能概述

资产演变模块可视化展示策略在不同运行模式下的资产价值变化曲线和关键指标。

#### 界面布局

```
资产演变
├─ 模式选择器
│  ├─ [回测] [模拟盘] [实盘]
│  └─ 当前选中模式高亮显示
│
├─ 资产曲线图表
│  ├─ 时间轴（X 轴）
│  ├─ 资产价值（Y 轴）
│  ├─ 策略曲线（主要数据）
│  └─ 基准曲线（QQQ，可选）
│
├─ 关键指标卡片
│  ├─ 初始资金
│  ├─ 当前资产
│  ├─ 总收益率
│  ├─ 最大回撤
│  ├─ 夏普比率
│  └─ 交易天数
│
└─ 时间范围选择
   ├─ 全部时间
   ├─ 最近一周
   ├─ 最近一月
   └─ 自定义范围
```

#### 三种模式展示

##### 1. 回测（Backtest）

**特点**：
- 使用历史数据运行策略
- 无资金风险
- 可以快速验证策略有效性

**展示内容**：
- 资产净值曲线（基于历史价格计算）
- 历史收益率、最大回撤等指标
- 交易日期范围
- 交易记录（可选）
- **AI 思考日志**：显示每日 AI 的决策过程和推理步骤（调试重要部分）

**数据来源**：
- `data/strategies/{strategy_id}/backtest/agent_data/`
- `data/strategies/{strategy_id}/backtest/agent_data/log/{date}/log.jsonl`

##### 2. 模拟盘（Simulate）

**特点**：
- 使用实时市场数据
- 模拟交易执行
- 无资金风险，但验证真实市场反应

**启动方式**：
- **手动启动**：点击"运行模拟"按钮，立即开始交易
- **自动启动**：
  - 如果配置了"自动启动"，系统启动时会自动开始交易
  - 修改 Prompt 后，可以选择是否自动重启并开始交易
  - 建议：修改 Prompt 后手动重启，确保新 Prompt 生效

**交易执行**：
- 策略会根据当前 Prompt 和配置自动进行交易决策
- 每次交易都会记录到日志文件
- 交易日志实时显示在界面上

**展示内容**：
- 实时资产净值曲线
- 模拟收益、当前持仓
- 实时市场数据来源标识
- **交易记录**（必显示，实时更新）
- **AI 思考日志**：显示每日 AI 的决策过程和推理步骤（调试重要部分）
  - 可按日期查看历史日志
  - 显示完整的对话记录（用户查询、AI 回复、工具调用结果）
  - 支持代码高亮和格式化显示

**数据来源**：
- `data/strategies/{strategy_id}/simulate/agent_data/`
- `data/strategies/{strategy_id}/simulate/agent_data/log/{date}/log.jsonl`（AI 思考日志）
- Moomoo 模拟账户数据

##### 3. 实盘（Real）

**特点**：
- 使用实时市场数据
- 真实交易执行
- 涉及真实资金，需要严格监控

**启动方式**：
- **手动启动**：点击"运行实盘"按钮，需要二次确认
- **自动启动**：
  - 如果配置了"自动启动"，系统启动时会自动开始交易（⚠️ 高风险）
  - 修改 Prompt 后，不建议自动重启实盘交易
  - 建议：修改配置后，手动检查并确认后再启动

**交易执行**：
- 策略会根据当前 Prompt 和配置自动进行交易决策
- **每次交易都会记录到日志文件**（重要：用于审计和回溯）
- 交易日志实时显示在界面上
- 风险控制参数自动生效

**展示内容**：
- 真实资产净值曲线
- 实际收益、当前持仓
- 风险控制状态
- **交易记录**（必显示，实时更新）
- **AI 思考日志**（必显示，显示每次交易的详细信息，调试和审计重要部分）
  - 可按日期查看历史日志
  - 显示完整的对话记录（用户查询、AI 回复、工具调用结果）
  - 支持代码高亮和格式化显示
  - 用于交易决策的回溯和审计
- 警告提示（高风险操作）

**数据来源**：
- `data/strategies/{strategy_id}/real/agent_data/`
- `data/strategies/{strategy_id}/real/agent_data/log/{date}/log.jsonl`（AI 思考日志）
- Moomoo 实盘账户数据

#### 模式切换功能

- **切换模式**：点击模式标签切换显示对应的数据
- **对比模式**：可选显示多个模式的数据进行对比
- **数据同步**：自动从后端获取最新数据
- **加载状态**：显示数据加载进度

#### 图表交互功能

- **缩放**：支持鼠标滚轮缩放
- **拖拽**：支持拖拽查看不同时间段
- **悬停提示**：鼠标悬停显示具体数值
- **导出**：导出图表为图片或 CSV 数据

#### AI 思考日志功能

**功能位置**：资产演变模块下方

**功能说明**：
- **日期选择**：下拉菜单选择要查看的日期
- **日志展示**：
  - 显示该日期所有 AI 对话记录
  - 包括用户查询、AI 回复、工具调用结果
  - 按时间顺序展示，最新记录在下方
  - 支持代码高亮（Markdown 代码块）
  - 支持格式化显示（换行、缩进等）

**日志内容**：
- **时间戳**：每条日志的精确时间
- **模型标识**：显示使用的 AI 模型（signature）
- **对话记录**：
  - 用户消息（蓝色标识）
  - AI 回复（绿色标识）
  - 工具调用结果
  - AI 的推理过程
  - 决策依据

**使用场景**：
- **调试**：查看 AI 为什么做出某个交易决策
- **优化**：分析 AI 的推理过程，优化 Prompt
- **审计**：实盘交易时，记录完整的决策过程用于审计
- **学习**：了解 AI 如何处理市场信息和做出决策

**日志格式**：
- 存储格式：JSONL（每行一个 JSON 对象）
- 文件路径：`data/strategies/{strategy_id}/{mode}/agent_data/log/{date}/log.jsonl`
- 数据结构：
  ```json
  {
    "timestamp": "2025-10-02T10:30:00",
    "signature": "deepseek-chat-v3.1",
    "new_messages": [
      {
        "role": "user",
        "content": "Please analyze and update today's positions."
      },
      {
        "role": "assistant",
        "content": "AI 的回复内容..."
      }
    ]
  }
  ```

**API 端点**：
- `GET /api/strategies/{strategy_id}/logs/dates/{mode}` - 获取可用的日志日期列表
- `GET /api/strategies/{strategy_id}/logs/{mode}/{date}` - 获取指定日期的日志内容

```
投资组合分析

├─ 持仓详情
│  ├─ 股票代码
│  ├─ 持仓数量
│  ├─ 成本价
│  ├─ 当前价
│  ├─ 市值
│  ├─ 盈亏
│  └─ 盈亏比例
│
├─ 交易记录（实时更新）
│  ├─ 日期时间
│  ├─ 操作（买入/卖出）
│  ├─ 股票代码
│  ├─ 数量
│  ├─ 价格
│  ├─ 总金额
│  └─ 交易状态（成功/失败）
│
├─ 风险指标

└─ 资产分布
   ├─ 股票持仓分布（饼图）
```

#### 功能特性

## 🔧 核心功能说明

### 1. 策略删除功能

#### 功能设计

- **删除入口**：策略卡片上的"删除"按钮（红色，位于右下角）
- **删除确认**：
  - 显示策略信息（名称、创建时间、当前状态）
  - 警告提示：删除操作不可恢复
  - 如果策略正在运行，提示先停止运行
- **删除范围**：
  - 策略配置目录：`configs/strategies/{strategy_id}/`
  - 策略数据目录：`data/strategies/{strategy_id}/`
  - 包含所有模式的数据（回测、模拟、实盘）

#### 安全考虑

- ⚠️ 删除操作需要二次确认
- ⚠️ 运行中的策略不能删除
- ⚠️ 实盘策略删除需要额外确认（高风险）

---

### 2. 交易日期范围配置

#### 设计原则

**交易日期范围仅用于回测模式**，因为：
- 回测需要明确的历史日期范围来测试策略
- 模拟盘和实盘使用实时市场，不需要预设日期范围
- 模拟盘和实盘的日期范围是动态的（从启动到停止）

#### 配置位置调整

- **旧设计**：配置管理中统一显示所有模式的日期范围
- **新设计**：
  - 配置管理模块添加模式选择器
  - 选择"回测"模式时，显示"交易日期范围"配置项
  - 选择"模拟盘"或"实盘"模式时，不显示日期范围配置（或显示"实时运行，无需设置日期范围"）

#### 界面展示

```
配置管理
├─ 模式选择：[基础配置] [回测] [模拟盘] [实盘]
│
├─ 基础配置（所有模式共用）
│  ├─ Agent 参数
│  ├─ 模型配置
│  └─ 基础 Prompt
│
├─ 回测配置（仅回测模式）
│  ├─ 交易日期范围 ← 只有这里显示
│  │  ├─ 开始日期
│  │  └─ 结束日期
│  └─ 历史数据设置
│
└─ 模拟盘/实盘配置
   └─ 提示：实时运行，无需设置日期范围
```

---

### 3. 配置修改和重启服务

#### 配置修改流程

1. **修改配置**：
   - 用户在配置管理界面修改参数
   - 点击"保存配置"按钮
   - 配置保存到文件

2. **提示重启**：
   - 保存成功后显示提示："配置已保存，需要重启服务才能生效"
   - 显示"重启服务"按钮（高亮显示）

3. **重启服务**：
   - 点击"重启服务"按钮
   - 确认对话框：
     - 如果策略正在运行：提示"重启将停止当前运行的任务，是否继续？"
     - 如果策略未运行：提示"是否重启服务以应用新配置？"
   - 确认后重启服务
   - 重启完成后，新配置生效

#### 重启服务按钮位置

- **配置管理模块**：保存配置后，在操作按钮区域显示"重启服务"按钮
- **策略详情页面顶部**：也可以添加快速重启按钮（可选）

#### 技术实现

- 重启服务 = 重启 `main.py` 进程
- 通过 API 调用：`POST /api/restart-main`
- 如果策略正在运行，先停止再重启

### 4. 模拟盘和实盘的启动逻辑

#### 模拟盘启动方式

**方式一：手动启动**
- 用户点击"运行模拟"按钮
- 立即开始交易
- 使用当前配置的 Prompt 和参数

**方式二：自动启动**（可选）
- 在模拟盘配置中设置"自动启动"开关
- 系统启动时，如果策略配置了自动启动，则自动开始交易
- **修改 Prompt 后**：
  - 如果启用了自动启动，可以选择是否自动重启并开始交易
  - 建议：修改 Prompt 后手动重启，确保新 Prompt 生效

#### 实盘启动方式

**方式一：手动启动**（推荐）
- 用户点击"运行实盘"按钮
- 需要二次确认（高风险操作）
- 确认后开始交易

**方式二：自动启动**（不推荐）
- 虽然技术上支持，但**强烈不推荐**实盘自动启动
- 如果必须启用，需要：
  - 多重确认
  - 风险提示
  - 日志记录

#### 修改 Prompt 后的处理

**最佳实践**：
1. 修改 Prompt
2. 保存配置
3. 手动重启服务（确保新 Prompt 生效）
4. 手动启动交易（确保控制权）

**自动处理**（可选）：
- 如果配置了自动启动，修改 Prompt 后可以：
  - 提示用户是否重启并开始交易
  - 用户确认后，重启服务并开始交易

每次交易都会记录详细日志，包括：

   - 股票代码
   - 数量

```
data/strategies/{strategy_id}/
├── backtest/
│   └── log/
```

- 添加"交易日志"标签页
- 显示日志列表（按时间倒序）
- 支持搜索和筛选
- 点击日志项查看详细信息

**日志详情视图**：
- 显示完整的交易日志
- 包括 AI 决策过程
- 工具调用记录
- 执行结果

#### 日志重要性

- **回测**：用于分析策略决策过程
- **模拟盘**：用于验证策略在真实市场中的表现
